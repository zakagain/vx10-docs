# Reconnaissance

## Mach 10 Reconnaissance


VX-10 uses SAR, **Synthetic Aperture Radar.** SAR works by sending out pulses and using the movement of the craft to create a huge “virtual” antenna. No matter the condition, we can fabricate 3D maps to the **_centimetre._**


## Vectura Speed Panel


If you have read any more of this documentation, you will know about the **Vectura Speed Panel.** When in reconnaissance mode, it becomes a live 3D map of the terrain, utilising onboard **SAR** technology.
